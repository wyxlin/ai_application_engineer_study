**Week 7 — Evaluation and Debugging**
**Session:** Built LLM-graded eval system for Portfolio Document QA

## What I built

Eval pipeline (`projects/rag/eval_qa.py`):
- 5 test cases with expected keywords
- QA chain retrieves and answers each question
- Grader chain scores each answer 1-5 using LLM
- Saves results to `eval_results.json`

### Results
- Average score: 5.0/5
- Cases passed (≥4): 5/5

---

## Key lessons

1. **Eval cases that are too easy give perfect scores** — add harder cases that require inference or test failure modes
2. **The eval loop**: change prompt → run eval → did score drop? revert. Did it improve? keep it.
3. **Two grading approaches**: exact match for structured output, LLM-graded for natural language answers
4. **Always save eval results to JSON** — track scores over time to catch regressions
