## What I studied

### Lesson 2: Classification
- Classification routes user input into categories so the program knows which workflow to run
- Handle low confidence by asking the user to clarify
- Handle off-topic input (`category: "other"`) with a polite rejection
- When a message touches two categories, set a primary and put secondary in `also_related_to`

### Lesson 3: Moderation
- Moderation sits before the classifier — it's the first gate in the pipeline
- Uses OpenAI's dedicated moderation endpoint (`client.moderations.create`) — free, no token cost
- More reliable than a general prompt because it uses a model trained specifically for safety
- `flagged=True` means stop the pipeline immediately

### Lesson 4: Chain of Thought
- Forces the model to reason step by step before concluding
- Improves accuracy for complex tasks (job fit evaluation) but not needed for simple routing
- Always put `reasoning` inside the JSON — never let the model write free text before JSON or `json.loads()` breaks

### Lesson 5: Chaining Prompts
- Break complex tasks into focused steps — each step's output feeds the next
- Pass structured JSON between steps, not raw text
- Only the final step returns natural language to the user
- Always wrap `json.loads()` in a try/except block

### Lesson 6: Check Outputs
- Mirror of input moderation — checks the model's output before it reaches the user
- Moderation check is free, always run it on output
- Quality check costs tokens — only run it on the final response, not every intermediate step
- If output fails, return a fallback message

### Lesson 7: Evaluation
- Systematically measure how well your system works
- Exact match for structured outputs (classification, scores)
- LLM-graded for natural language outputs (explanations, summaries)
- Start collecting eval cases now — every manual test is a potential test case
- Before changing a prompt, run existing eval cases first to catch regressions

- Regression checking: changing a prompt can quietly break cases that already worked — eval dataset catches this
