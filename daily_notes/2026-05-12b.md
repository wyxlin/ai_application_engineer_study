## What I studied

### Two types of memory
| Type | Stores | Example |
|---|---|---|
| Short-term | Current conversation | Messages from this session |
| Long-term | Persistent preferences | "User prefers remote jobs" |

### MemorySaver — in-memory checkpointer
```python
from langgraph.checkpoint.memory import MemorySaver

memory = MemorySaver()
agent = create_react_agent(llm, tools=tools, checkpointer=memory)
```

### thread_id — conversation identifier
```python
config = {"configurable": {"thread_id": "session_001"}}

# Turn 1 — agent searches and remembers
agent.invoke({"messages": [("user", "Find backend jobs in Seattle")]}, config)

# Turn 2 — agent remembers Turn 1 without re-searching
agent.invoke({"messages": [("user", "Which one pays more?")]}, config)
```

Same `thread_id` = same conversation. Different `thread_id` = fresh start.

---

## Key lessons

1. **`checkpointer=memory`** — correct parameter name (not `checkpoint`)
2. **`thread_id`** is the conversation key — use user ID or session ID in production
3. **`MemorySaver` is in-RAM only** — disappears on restart
4. **Production memory**: use `PostgresSaver` backed by a real database
